## ⚡ Install

Copy any skill folder into your agent's skills directory:

```bash
git clone https://github.com/Sheeshkidayyy/Skills.git
cp -r Skills/general/documenter <your-agent-skills-dir>/
```

Each folder contains a `SKILL.md` (the instructions), optional `references/` for deeper detail, and optional `agents/` metadata.

---

## 🧪 Provenance and safety

- 👀 Review a skill's instructions before using it in a new environment, especially where content publication or deployment is involved.
- 🙅 Skills never authorize pushes, releases, or deployments on their own; that always comes from you.
